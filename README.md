# 時報くん

ブラウザで動くシンプルな時報アプリです。スタートボタンを押すと、1分ごとに現在時刻をWeb Speech APIで読み上げます。停止したい場合はもう一度ボタンを押してください。

## 使い方
1. `index.html` をChromeなどのブラウザで開きます。
2. 画面中央の「スタート」ボタンを押してマイクアクセスを許可します（必要な場合）。
3. 以降1分ごとに「ただいまの時刻は◯時◯分です」とアナウンスされます。
4. 止めたい場合は「ストップ」ボタンを押します。

Web Speech APIに対応していないブラウザでは読み上げは行われませんが、時計表示は機能します。
