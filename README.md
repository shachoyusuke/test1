# ホロクロック時報ポータル

Chrome / Safari (WebKit) で「こんなことまでブラウザでできんの！？」って驚いてほしい、変態的な時報アプリや。WebXR対応の3D空間に浮かぶ時計をA-Frameで描画して、Tone.jsがジェネラティブな宇宙サウンドを鳴らし、Web Speech APIで1分ごとにしゃべり倒す仕掛けになっとる。

## 何が起きるん？
- **ホログラムみたいな時計ポータル**: A-Frameで自前コンポーネントを組んで、数字がぐるぐる回るリボンと星空パーティクルを生成。マウスでもVRヘッドセットでも覗き込める。
- **ジェネラティブ時報サウンド**: Tone.jsで組んだFM/Metalシンセが時刻に合わせてコードを放出。毎分鳴るチャイムは時刻によって和音が変わるし、BGM的なループもランダム生成や。
- **音声読み上げ**: Web Speech APIが1分ごとに現在時刻を読み上げる。読み上げOFFやチャイムOFFもUIから切り替え可能。

## 使い方
1. `index.html` をChromeやSafariなどWebXR/Audio対応ブラウザで開く。
2. 画面上部の「ポータルを開く」をクリック（またはタップ）。初回は音声再生許可を求められるかも。
3. 銀河っぽい空間に浮かぶ時計が動き出して、1分ごとに音声とサイバーなチャイムが鳴る。読み上げやBGMはトグルで切り替えられる。
4. VRゴーグルがあるなら、画面右下の「Enter VR」ボタンからWebXRモードに突入して、本当にその場に時計が浮いてる感じを体験できるで。

## プレビュー方法
ローカルで試すときは、静的ファイルとして開いても動くけど、音声周りがブロックされることがあるから簡易サーバー経由がおすすめや。

### 1. ファイルを直開き
`index.html` をダブルクリックしてブラウザで開くだけ。ただしブラウザ設定によっては音声が止められる場合がある。

### 2. 簡易Webサーバーを立てる
```bash
# プロジェクトのルートで実行
python3 -m http.server 8000
```
ブラウザで `http://localhost:8000/index.html` にアクセスすれば、音声許可が通りやすいし、VRモードも安定する。

## ちょっとしたTips
- Tone.jsのサウンドはユーザー操作後にしか鳴らん仕様やから、必ず「ポータルを開く」を押してな。
- 読み上げが動かへん場合は、ブラウザの設定で音声合成が許可されてるか確認。
- VRモードはWebXR対応デバイスのみやけど、PCの画面でもマウスドラッグ＆WASDで動き回れるで。

## 主な技術スタック
- [A-Frame](https://aframe.io/) — WebXR対応の3Dフレームワーク。自作コンポーネントでホロ演出をしてる。
- [Tone.js](https://tonejs.github.io/) — ブラウザでシンセサイザーを鳴らすための音響ライブラリ。FM/MetalシンセやLoopでジェネラティブ音を生成。
- Web Speech API — 毎分の時報を日本語で読み上げ。

この3つを同時に使う機会なんて滅多にないはずやから、ネタとしてもインパクト満点やで。楽しんでな！
